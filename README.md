# bingus_warriors cool converter

A private, on-device toolbox for video, audio, image, PDF, document, ZIP, and data conversion.

## Website

The public GitHub Pages site lives in `docs/`. It is a product and download page. The Windows and Android apps perform conversions on the user's device.

## Releases

The page links to the latest GitHub Release. Publish a release containing these exact asset names:

- `Still-Toolbox-Windows-v3.zip`
- `Still-Android.apk`
- `Still-Android-Source.zip` (optional)

## Local data and secrets

Do not commit saved `Audio/` or `Files/` folders, conversion histories, temporary files, personal media, Android signing keys, passwords, or build artifacts.
